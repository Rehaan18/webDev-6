📘 Project Description – Assignment Vault
Assignment Vault is a simple web-based navigation portal that provides organized access to academic assignments. It serves as a centralized platform where students can easily browse and access subject-wise or topic-wise assignments through a structured interface.
The homepage contains:
  • A clear and bold title section for identification.
  • A navigation table labeled Assignment Navigation Portal.
  • Topic-wise assignment listing.
  • Radio button-based selection system for accessing assignment pages.
  • A clean tabular layout for better readability and structured presentation.

🎯 Objective of the Project
The main objective of this project is to:
  • Provide an organized digital vault for assignments.
  • Improve accessibility and navigation between assignment pages.
  • Demonstrate the use of basic HTML elements such as:
    • Tables
    • Forms
    • Radio buttons
    • Hyperlinks
    • Labels
